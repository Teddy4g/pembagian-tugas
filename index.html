Master Context

Penelitian mengevaluasi klasifikasi otomatis KBLI dengan pipeline: bukti web → Claude Haiku 4.5 sebagai summarizer → text-embedding-3-small → retrieval hierarkis Level 1 → Level 2 → Level 3 dengan pure cosine similarity → Top-10 kandidat Level 3 → Claude Haiku 4.5 sebagai semantic judge. RQ1 menguji pengaruh Claude summary terhadap kualitas retrieval dibanding raw web evidence. RQ2 menguji pengaruh Claude Judge terhadap exact-match accuracy dibanding Cosine Top-1. Eksperimen wajib menggunakan E0, E1, dan E2. BM25, hybrid search, smart fallback, dan Qwen berada di luar scope.
