# ICAISD Paper Workspace

Static HTML workspace untuk pembagian penulisan paper.

## Deploy ke Vercel
1. Upload folder ini ke GitHub atau import langsung ke Vercel.
2. Framework Preset: **Other**.
3. Build command: kosong.
4. Output directory: kosong / root.

Semua progress draft dan checklist disimpan melalui localStorage browser masing-masing anggota.
